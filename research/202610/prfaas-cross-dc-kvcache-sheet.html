Part 2: Mechanisms
  • Length threshold tUncached length > t → PrfaaS
  • Hybrid prefix cache poolLinear state + full-attn KV share one block pool
  • TransportLayer-wise pipelining · multi-conn TCP · loss signals
  • Dual-timescale schedulerShort: re-tune t · Long: move PD nodes P↔D
Enabler: hybrid attentionOnly full-attention layers (1 of 4 to 1 of 8) hold KV that grows with length. Φkv drops 4–13× against dense models.
Block typesprefix-cache: full, aligned, reusable, stays in cluster · transfer-cache: any length, sent to decode, then freed

Smaller KV is necessary but not sufficient. Selective offload and scheduling make it work.

Throughput model and routing

§2.1 · §3.4 · Eqs. 1–8

1 KV throughput of one instance (Eq. 1)

Φkv(l) = S_kv(l)KV bytes for length l / T_prefill(l)Prefill time, near-quadratic
Cluster egress need (Eq. 2): B_out ≈ (N/P) · Φkv(L_avg), with L_avg = mean uncached length offloaded.

2 Stage capacities (Eqs. 3–5)

Θ_prfaas = min(N_prfaas/T(l_long),Compute ceiling B_out/S_kv(l_long))Bandwidth ceiling
Θ_pd-p = N_p/T(l_short)RDMA never binds Θ_pd-d = N_d·BS_max/(T_dec·L_out)SLO-fixed constants

3 System rate and optimum (Eqs. 6–8)

Λ_max = min(Θ_prfaas/p,p = P(L>t) offloaded Θ_pd-p/(1−p),Rest stays local Θ_pd-d)Decode sees all
Optimum: Θ_prfaas/p = Θ_pd-p/(1−p) and Θ_prfaas + Θ_pd-p = Θ_pd-d. Grid search over t and N_p/N_d → t = 19.4K, N_p/N_d = 3/5.

4 Cache-aware routing rule (§3.4.3)

l = l_total − l_pdBandwidth scarce | l_total − max(l_prfaas, l_pd)Bandwidth abundant: may ship prefix ; l > t ? PrfaaS : PD-PThen route
Long term: queue depth and utilization show the bound stage. The scheduler converts PD nodes between P and D, then re-tunes t.
